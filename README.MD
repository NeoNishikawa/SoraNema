## ✨ Fitur


- **Detail + episode** — daftar episode, player mirror, label episode, kontrol Lengkap.
- **Unduhan link-out** — resolusi → sumber (Masu/Mega) → tautan; host difilter server (Google Drive, Mega, MediaFire, Pixeldrain).
- **Local Storage** — koleksi, progres, favorit, import/export, edit mode, sediakan data tanpa server.
- **Lanjutkan Menonton + Rekomendasi Genre** — rail horizontal, satu baris kartu yang bisa digeser.
- **Screen time** — penghitung waktu menonton, ambang, aman multi-tab.
- **Spring-clean** — pemeliharaan katalog & pencarian otomatis, data pribadi tidak hilang.

## 🤖 SoraNema — Android APK

Aplikasi streaming anime native untuk Android — tanpa akun, tanpa server antara, tanpa ribet.

- **Streaming native** — player video bawaan; sumber video yang tidak bisa diputar langsung dibuka lewat browser.
- **Populer Hari Ini & Update Harian** — katalog dan daftar episode terpilih, langsung dari aplikasi.
- **Lanjutkan Menonton** — progres tersimpan per anime; ketuk kartu untuk langsung lanjut ke episode berikutnya.
- **Pencarian & filter genre** — ketik judul atau tambahkan `/genre:romansa,isekai` untuk menyaring.
- **Koleksi** — simpan anime favoritmu, hapus banyak sekaligus, ekspor/impor koleksi ke file JSON.
- **Profil** — level & episode ditonton, ekspor/impor data, mode offline (belum ada unduhan — fitur menyusul segera).
- **Intro SoraNema** — setiap kali aplikasi dibuka, sistem intro diputarkan; data aplikasi dimuat di latar selama intro berjalan — begitu selesai, halaman langsung terisi.

**Unduh** — buka [Releases — tag `apk`](https://github.com/NeoNishikawa/SoraNema/releases/tag/apk), ambil `SoraNema-I0.V1-release.apk` (±5,3 MB), pasang di Android dengan mengaktifkan "Install dari sumber tidak dikenal" bila diminta sistem. SHA-256 tercantum di rilis tersebut. Seluruhnya gratis — tidak ada biaya tersembunyi.
