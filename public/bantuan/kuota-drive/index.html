Kuota Drive sedang penuh

Google membatasi unduhan file ini untuk sementara. Ini bukan batas dari SoraNema, dan file-nya tidak hilang. Kuota biasanya pulih sendiri, kadang sampai 24 jam.

Jangan klik berulang. Klik terus-menerus tidak mempercepat kuota. Pilih mirror lain dulu, lalu kembali ke Drive nanti.

Tiga langkah yang paling cepat

  1. 1
    Kembali ke halaman detail.

    Buka batch yang sama, lalu pilih resolusi lain dari dropdown. Jangan tutup halaman detail kalau belum mencoba mirror lain.

  2. 2
    Pakai mirror selain Google Drive.

    Pixeldrain, MediaFire, atau Mega. Ketiganya membuka tab baru; itu normal karena hostnya tidak mengizinkan unduhan same-tab.

  3. 3
    Coba Drive lagi nanti.

    Beri jeda beberapa jam atau coba besok. File yang sama bisa tersedia lagi tanpa perlu diunggah ulang.

Pertanyaan umum

Apakah file saya hilang?

Tidak. File tetap ada di Google Drive. Yang dibatasi adalah jumlah orang yang boleh mengunduhnya dalam waktu tertentu. Ini pengaman Google, bukan file yang dihapus.

Kenapa hanya Drive yang diunduh di tab yang sama?

Drive mengirim file sebagai lampiran, jadi browser bisa mengunduhnya tanpa berpindah halaman. Pixeldrain menolak unduhan lintas situs dengan 403, Mega memakai enkripsi, dan MediaFire membuka halamannya sendiri — karena itu ketiganya menjadi link-out ke tab baru. Kenapa Pixeldrain menolak unduhan langsung?

Apakah SoraNema membatasi ukuran file?

Tidak. Satu klik ke tombol Drive hanya satu permintaan; byte file mengalir langsung dari host ke browser, bukan lewat server SoraNema. Batas burst di server hanya mencegah spam klik, bukan membatasi ukuran file.

Sudah lama, tapi masih kuota. Harus bagaimana?

Pilih mirror lain atau batch lain di halaman detail. Kalau semua mirror mati, kemungkinan tautannya sudah kedaluwarsa dan perlu diunggah ulang oleh pemilik file.
